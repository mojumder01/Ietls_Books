Voice Change



Active Voice: Subject does the action. (কতņা কাজ কের)

o

Example: The chef cooks the meal. (Chef কাজ করেছ)



Passive Voice: Subject receives the action. (কতņা কােজর ভুেভাগী)

o

Example: The meal is cooked by the chef. (Meal কাজ পােōছ)

When to Use Passive Voice



When the doer is unknown: The wallet was stolen. (hক িনেয়েছ জানা hনই)



When the doer is unimportant: English is spoken worldwide. (কারা বেল তা রŇÉপূণņ নয়)



To be formal/polite: The request has been declined. (Formal tone)



For scientific/process description: The mixture is heated to 60°C.

Steps to Change Active to Passive

1. Identify Subject, Verb, Object. (Subject, Verb, Object śলাদা কেরা)

2. Move object to subject position.

3. Choose correct to be form based on tense.

4. Use past participle of the main verb.

5. Add “by + agent” only if needed.

6. Keep other sentence parts unchanged.

Rule 1: Simple Tenses (Present, Past, Future Simple)

Structure

Active Form:

• Present Simple: Subject + base verb + object → (এখােন subject verb-এর মূল রňপ বńবহার কের object-এর

ওপর কাজ কের)

• Past Simple: Subject + past verb + object → (verb-এর past form বńবহার হয়)

• Future Simple: Subject + will/shall + base verb + object → (ভিবষńৎ hবাঝােত will/shall + base verb)

Page 2 / 9

Passive Form:

• Present: Object + am/is/are + past participle (+ by + agent) → (object-এর ওপর কাজ হেōছ, verb-এর past

participle বńবহার হয়)

• Past: Object + was/were + past participle (+ by + agent) → (was/were িদেয় অতীত passive jতির হয়)

• Future: Object + will/shall + be + past participle (+ by + agent) → (will/shall + be + past participle)

Examples:

• Present: They write letters → Letters are written by them. (Present passive)

• Past: The manager approved the plan → The plan was approved by the manager. (Past passive)

• Future: We will announce the results → The results will be announced. (Future passive)

Exceptions:

• Object must exist; “by + agent” optional. (object না থাকেল passive হেব না)

• Plural → use are/were, singular → use is/was. (বĺবচন হেল are/were, একবচন হেল is/was)

• Future Simple passive is more formal. (future passive সাধারণত hবিশ আনুĥািনক)

Common Mistakes & Fixes:

• Wrong: Letters written by them. Right: Letters are written by them. (be verb বাদ িদেত হেব না)

• Avoid passive if no object: He goes to school → keep active. (object না থাকেল passive অôাকৃত hশানায়)

Rule 2: Continuous Tenses (Present, Past Continuous)

Structure

Active Form:

• Present: Subject + am/is/are + verb-ing + object (present progressive কাজ hবাঝােত)

• Past: Subject + was/were + verb-ing + object (past progressive কাজ hবাঝােত)

Passive Form:

• Present: Object + am/is/are + being + past participle (being hযাগ হয় continuous passive-এ)

• Past: Object + was/were + being + past participle

Examples:

• Present: She is baking a cake → A cake is being baked by her.

• Past: They were repairing the road → The road was being repaired by them.

Notes:

• Less common in spoken English. (jদনিŐদন কথায় খুব hবিশ বńবĻত হয় না)

• Rare in academic writing for Past Continuous. (একােডিমক hলখায়ও rare)

• Future Continuous passive is very rare and usually avoided. (Future Continuous passive ôায় বńবহার হয়

না)

Rule 3: Perfect Tenses (Present, Past, Future Perfect)

Structure

Active Form:

• Present: Subject + has/have + past participle + object (কাজ hশষ হেয়েছ hবাঝােত)

• Past: Subject + had + past participle + object (অতীেত কাজ hশষ)

• Future: Subject + will/shall + have + past participle + object (ভিবষńেত িনŊদ ģ সমেয় কাজ hশষ হেব)

Passive Form:

• Present: Object + has/have + been + past participle (been সবসময় থাকেব)

• Past: Object + had + been + past participle

• Future: Object + will/shall + have + been + past participle

Examples:

• Present: He has finished the work → The work has been finished by him.

• Past: She had completed the project → The project had been completed by her.

• Future: They will have finished the work → The work will have been finished.

Notes:

• Always include been in passive. (been বাদ িদেল ভুল হেব)

• Past Perfect passive is common in formal reports. (Formal report-এ hবিশ বńবĻত হয়)

• Future Perfect passive appears in reports/predictions. (prediction/report-এ বńবĻত হয়)

Rule 4: Modals (can, could, may, might, must, should, will, shall, would,

ought to, etc.)

Structure

Active Form:

Subject + modal verb + base verb + object (Modal verb কােজর সĈাবনা, অনুমিত, ôেয়াজন বা বাধńবাধকতা

hবাঝােত বńবĻত হয়। hযমন can মােন পারা, must মােন অবশńই করেত হেব)

Passive Form:

Object + modal verb + be + past participle (+ by + agent) (Passive-এ modal verb অপিরবŊত ত থােক, ęধু base

verb-এর ĳেল be + past participle śেস)

Explanation:

Modals are used to show ability, permission, necessity, or possibility. In passive form, the focus shifts

from the doer (agent) to the receiver (object) of the action. Active-এ কােজর কতņ া hবাঝােনা হয়, Passive-এ

কােজর ভুেভাগী বা ôাপকেক রŇÉ hদওয়া হয়। িকছু modal hযমন must have, could have, should have passive-

Example (Active → Passive):

Active: The teacher says we must finish the project by Monday. We can submit it online or in person. The

team should review all the details carefully. We might need to add some charts to explain our ideas.

Finally, we must present it to the class.

Passive: The project must be finished by Monday. It can be submitted online or in person. All the details

should be reviewed carefully. Some charts might need to be added to explain the ideas. Finally, it must

be presented to the class.

1. Omitting “be” in passive (be verb বাদ িদেল ভুল হেব)

o

o

Right: The task should be completed today.

2. Incorrect past participle

o

Wrong: The rules must be follow.

o

Right: The rules must be followed.

3. Unnecessary “by + agent” (যখন agent hবাঝাই যায়, তখন বাদ িদন)

o

Right: The laws must be obeyed.

Rule 5: Reporting Passive

Structure

Active Form:

People/Experts/Authorities say/think/believe/know + that + clause (এখােন অেনńর কথা, ধারণা বা তথń িরেপাটņ

করা হয়)

Passive Forms:

1. It + is/was + past participle + that + clause (এŠট সবেচেয় সাধারণ ও formal form)

2. Subject + is/was + past participle + to-infinitive (এŠট সংিð িকäু একই অথņ ôকাশ কের)

Explanation:

Reporting passive is used to report beliefs, opinions, or statements without focusing on who said them.

এর মােন দাঁড়ায় — hক বেলেছ hসটা রŇÉ না িদেয়, কী বলা হেয়েছ hসŠট তুেল ধরা।

Example (Active → Passive):

Active: People say the city is one of the safest in the country. Experts believe the government has

reduced crime rates. Many citizens think the police are doing a great job. Tourists know the city is full of

cultural attractions.

Passive: It is said that the city is one of the safest in the country. It is believed that the government has

reduced crime rates. It is thought that the police are doing a great job. It is known that the city is full of

cultural attractions.

Common Mistakes:



Wrong: It said that the city is safe.



Right: It is said that the city is safe.

Rule 6: Questions (Present & Past Simple)

Structure

Active Form:

• Present: Do/Does + subject + base verb + object? (বতņমান ôĜ)

• Past: Did + subject + base verb + object? (অতীত ôĜ)

Passive Form:

• Present: Am/Is/Are + object + past participle (+ by + agent)?

• Past: Was/Were + object + past participle (+ by + agent)?

Explanation:

Passive questions are used when we want to ask about the action or the receiver of the action, rather

than the doer. Passive ôেĜর মাধńেম কােজর কতņ ার hচেয় কােজর ফলাফেলর ôিত hবিশ রŇÉ hদওয়া হয়।

Example (Active → Passive):

Active: Do they sell tickets at this counter? Did she write the report last week? Does the shop offer free

delivery? Did the manager approve the plan?

Passive: Are tickets sold at this counter? Was the report written last week? Is free delivery offered by the

shop? Was the plan approved by the manager?

Common Mistakes:



Wrong: Did the report was written by her?



Right: Was the report written by her?

Rule 7: Imperatives (Commands & Negative)

Structure

Positive Commands:

Let + object + be + past participle (Formal িনেদņশ)

Negative Commands:

Let + object + not + be + past participle (িনেষধা«া িনেদņশ)

Explanation:

Imperatives in passive form are used for polite, formal, or written instructions (আেদশ, অনুেরাধ, hঘাষণা,

উপেদশ, ভÙতা ইতńািদ ).

Example (Active → Passive):

Active: Close all the windows before leaving. Do not touch the equipment. Follow the safety instructions

carefully. Keep the door locked at all times.

Passive: Let all the windows be closed before leaving. Let the equipment not be touched. Let the safety

instructions be followed carefully. Let the door be kept locked at all times.

Common Mistakes:



Wrong: Let the door closed.



Right: Let the door be closed.

Rule 8: Special Cases

Explanation:

Some sentences can’t be turned into passive due to grammar or meaning. Passive jতির করেত object

অবশńই থাকেত হেব এবং verb এমন হেত হেব যা passive-এ বńবহারেযাগń।

Types:

1. Without Object (No Passive)

o

Active: He sleeps a lot.

o

Passive: ✖ Not possible (no object). (hকােনা object না থাকেল passive হয় না)

2. Double Object Verbs (give, send, offer, show, etc.)

o

Active: They gave her a gift.

o

Passive 1: She was given a gift. (formal)

o

Passive 2: A gift was given to her. (less formal)

3. Verbs Without Passive Form

o

Stative verbs (have, fit, suit, belong)

o

Active: I have a car.

o

Passive: ✖ Not “A car is had by me.” (অĶাভািবক ও ভুল)

4. Process Description (Agentless Passive)

o

Active: They heat the liquid to 60°C.

o

Passive: The liquid is heated to 60°C. (Scientific tone)

Example Story:

Active: They give every student a handbook at the start of the course. The school offers free lunch to all

children. Some machines fit perfectly in the small workshop. Engineers heat the metal to 1200°C before

shaping it.

Passive: Every student is given a handbook at the start of the course. Free lunch is offered to all

children. (No passive for “fit” here.) The metal is heated to 1200°C before being shaped.



Infinitive:



Gerund:
